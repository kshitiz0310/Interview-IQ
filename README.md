## 📌 About The Project

**InterviewIQ.AI** is an AI-powered interview coach that helps you prepare for real job interviews. It simulates role-based technical and behavioral interviews, asks smart follow-up questions based on your answers, adapts difficulty on the fly, and generates instant performance reports — so you know exactly where you stand before the real thing.

> Because the best way to survive an interview is to have already survived a hundred fake ones. 😄

---

## ✨ Features

- 🎯 **Role-Based Simulations** — Technical & behavioral interviews tailored to the role
- 🧠 **Smart Follow-Ups** — AI asks contextual follow-up questions based on your responses
- 📈 **Adaptive Difficulty** — Question difficulty adjusts to your performance in real-time
- 📊 **Instant Performance Metrics** — Get a detailed report right after the interview
- 🗂️ **Reports History** — Review all your past mock interviews and track improvement
- 💳 **Credit-Based System** — Usage tracked via a simple credits model
- 🔐 **Secure Authentication** — Protected routes and user sessions

## ⚙️ Getting Started (Local Setup)

```bash
# Clone the repo
git clone https://github.com/kshitiz0310/Interview-IQ.git

# Go into the project folder
cd Interview-IQ

# Install dependencies (frontend)
cd client
npm install

# Install dependencies (backend)
cd ../server
npm install

# Run backend
npm run dev

# Run frontend (in a new terminal)
cd ../client
npm run dev
```

Create a `.env` file in the `server` folder with:

```env
MONGO_URI=your_mongodb_atlas_uri
PORT=5000
JWT_SECRET=your_secret_key
AI_API_KEY=your_ai_api_key
```
